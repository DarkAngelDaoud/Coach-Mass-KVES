 1. Files > Telechargements > coach-mass-kves-v13-8-a-envoyer.zip > Extraire.

--- Creation du logiciel (versions 1 a 5) ---
Point de depart : programme de prise de poids et de muscle a la maison, sans materiel (profil : 41 ans, 1,79 m, 75 kg,
objectif 80 kg, gros fumeur, budget alimentaire 100 dh/jour, travail sedentaire, 3 seances d'une heure par semaine).
Transforme en application web installable (PWA), hors ligne, legere, pour Pixel 8, avec un coach vocal francais strict.
 - Installation : pas a pas via GitHub Pages (depot public), faite depuis Chrome en "Version pour ordinateur",
   car l'application mobile GitHub ne permet pas d'envoyer des fichiers ni d'activer Pages.
 - Base : programme de seances au poids du corps, repas types (budget 100 dh), bilan du jour adaptatif, suivi du poids
   et des mensurations, objectifs, tableau de la semaine.
 - Seance guidee : voix francaise, vibrations, bips et signaux de fin d'exercice et de repos, metronome du tempo,
   compte des repetitions, ecran maintenu allume.
 - Illustrations : figures SVG animees pour chaque exercice (poses interpolees, modes boucle / manuel / maintien).
 - Graphiques : evolution du poids et de la performance par semaine et par periode ; historique des exercices et records.
 - Affichage : adapte a tous les telephones, portrait et paysage (barre laterale en paysage), rotation forcee en option.
 - Documentation : README.md complet (presentation, utilisation, utilite, 6 captures d'ecran).
Corrections de cette periode :
 - metronome des demi-repetitions impossible (minuteur trop lent) : corrige par un pas de 100 ms ;
 - poses incoherentes des fentes et des mollets : trajets redefinis ;
 - reglages deformes a 360 px de large : boutons de jours rendus flexibles ;
 - ecran qui refusait le paysage : le manifeste imposait "portrait" ; passe a "any", aucun verrou dans le code ;
 - README : plusieurs inexactitudes de texte corrigees (repos, metronome, mise a jour/cache).

D. LIMITES CONNUES
=====================================================================
 - Aperçu du lien (WhatsApp...) : non verifie en conditions reelles ; les applications gardent l'ancien aperçu en cache un certain temps.
 - Les calories sont des estimations ; les repas et la liste de courses gardent les aliments du plan de base (portions ajustées seulement dans Repas).
 - Les copies automatiques restent dans Chrome : seul le fichier exporte protege d'un telephone perdu ou d'un effacement des donnees du site.
 - Rappels : fiables application ouverte ; application fermee, Android peut les retarder ou les ignorer.
 - Calendrier (.ics) : non verifie sur ton Pixel ; ouvre le fichier avec Google Agenda.
 - Vibrations : a confirmer sur le Pixel (test dans Reglages > Coach).
 - Avis : l'identite (nom, e-mail) n'est pas verifiee ; pas d'accuse de reception ; si la cle du site (avis-config.js) est ecrasee,
   plus personne ne peut envoyer d'avis (les avis deja recus restent lisibles avec ta cle).
 - Contenu nutrition et exercices : reperes generaux, non relus par un professionnel de sante.
 - iPhone : installation manuelle, pas de vibration web ; une vraie application iOS demande un compte Apple et du code natif.
