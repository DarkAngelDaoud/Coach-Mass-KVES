MISE A JOUR VERSION 5 (option "Forcer la rotation") - depuis Chrome sur ton Pixel

1. Extrais coach-masse.zip avec l'application Fichiers.
2. Dans Chrome, ouvre github.com (Version pour ordinateur cochee), puis ton depot coach-masse.
3. Touche Add file > Upload files, puis choisis ces 3 fichiers :
   app.js, sw.js, manifest.webmanifest
4. Touche Commit changes. Attends 2 minutes.
5. Ouvre l'application avec internet, ferme-la completement, puis rouvre-la.
   Dans Reglages, tout en bas, tu dois lire "Version 5".
6. Dans Reglages > Affichage, active "Forcer la rotation de l'ecran", puis tourne le telephone.

EN CAS DE BLOCAGE : DIAGNOSTIC
A. Rotation automatique : glisse deux fois depuis le haut de l'ecran et verifie que "Rotation auto" est active.
B. Test dans Chrome : ouvre l'adresse de ton site dans un onglet Chrome (pas l'icone installee).
   Si l'ecran tourne la, le code est bon et c'est l'icone installee qui garde l'ancien reglage.
C. Verifie le manifest : ouvre https://darkangeldaoud.github.io/Coach-Mass-KVES/manifest.webmanifest
   Tu dois lire  "orientation": "any"  (et non "portrait"). Sinon, renvoie le fichier manifest.webmanifest sur GitHub.
D. Reinstalle : exporte tes donnees (Suivi > Exporter), appui long sur l'icone Coach > Desinstaller,
   puis rouvre l'adresse dans Chrome > menu > Installer l'application.


=== VERSION 6 : boîte à avis chiffrée + onglet Plus ===
1. Sur GitHub, remplace TOUS les fichiers du dépôt par ceux du zip (nouveau : avis-config.js).
2. Attends 2 minutes, ouvre l'application : onglet Plus > Espace propriétaire.
3. Crée ta clé (phrase secrète 10 caractères min.), puis « Sauvegarder ma clé » (garde le fichier).
4. Copie le texte affiché, ouvre avis-config.js sur GitHub, crayon, remplace tout, Commit changes.
5. Après 2 minutes, la boîte à avis est active pour tes amis. Ils t'envoient leur code, tu le colles dans Espace propriétaire.


=== VERSION 7 : courses, rappels, minuteur/compteur, theme ===
1. Dans le depot Coach-Mass-KVES, remplace TOUS les fichiers par ceux du zip (ne touche pas a avis-config.js si tu l'as deja rempli avec ta cle).
2. Attends 2 minutes, ferme completement l'application puis rouvre-la : Plus > A propos doit afficher la version 7.
3. Plus > Reglages > Rappels : active, regle les heures, appuie sur Tester et accepte les notifications.
